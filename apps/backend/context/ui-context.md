# UI Context (backend-focused)

This repository contains the backend service only. UI guidelines
live in the frontend repository and are out-of-scope here.

Notes for backend engineers:

- When producing email templates or HTML fragments, keep
  markup minimal and reuse templates in `templates/email/`.
- Public URLs for uploaded assets are generated by storage
  config; avoid embedding presentation logic in backend.

If you need to add frontend-facing tokens or palettes, update the
frontend repo's UI context and keep backend templates consistent
with those tokens.
